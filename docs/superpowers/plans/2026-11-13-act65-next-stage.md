# ACT首轮训练后的下一步安排

依据主机 `runs/act65_seed0_b8_10k_20261113_215406/metrics.jsonl` 的40次验证记录和当前训练入口制定。当前阶段为规划。

## 训练判断

| 步数 | 验证L1 | 验证总loss |
|---|---|---|
| 1000 | 0.14907 | 0.30973 |
| 5000 | 0.12129 | 0.14744 |
| 9000 | 0.11128 | 0.12340 |
| 10000 | 0.11068 | 0.12433 |

best.pt来自第9000步，last.pt来自第10000步。5000到10000步验证L1改善约8.7%，相应阶段最后500步平均训练L1从0.09731降到0.06771。验证误差总体缓慢下降，后半程收益趋缓，尚无持续上升的趋势。

当前L1为标准化后的14维动作平均，含相对静止的右臂维度。上游ACT将padding置零后仍按完整张量求平均，因此末帧窗口的数值会受有效长度影响。当前evaluate传入真实未来action，走CVAE后验动作重建分支。下一步补充部署时使用的 `policy(qpos,image)` 推理指标，按有效元素数计算误差，并单列活动左臂和夹爪。

## 1. 先完成实际推理模式的离线评估

- 使用现有10条验证episode、原55条训练归一化统计，比较best.pt和last.pt。
- 使用既有50个固定窗口，按有效action mask计算指标。还原到物理单位，分别报告左臂6关节MAE与P95（rad及度）、左夹爪MAE（0—1）和开合转换时序。
- 分别观察动作块第1步与后续30步误差。右臂单独报告，避免静止维度影响活动臂结论。
- 同一批窗口加入保持当前qpos的基线。挑选代表性和高误差片段，展示预测/示教关节曲线及抓取、插入、释放、撤离阶段。
- 输出两个checkpoint的对比表、误差曲线及候选模型。动作生成、动作反归一化、相机顺序均沿用当前数据契约。

## 2. 根据离线结果安排续训

- 若真实推理已明显优于保持姿态基线，仍有可改善的动作误差，从last.pt恢复模型与优化器，累计训练到20000步，新增10000步预计约45分钟。
- 沿用batch8、lr1e-5、chunk30、ResNet18及55/10划分。训练期间保留现有重建指标，并补充实际推理误差用于比较模型。
- 若失败集中在抓取/释放时间或某个操作阶段，先检查该阶段动作对齐、夹爪含义及数据覆盖，再选择针对性补数据或修改训练。
- 若训练误差继续下降而实际推理验证误差持续变差，保留此前候选模型，优先补充变化场景或针对性增强数据。

## 3. 准备真机推理接入

- 接入实时top/left图像、14维反馈、训练统计与候选checkpoint，先输出预测轨迹，检查左右臂映射、关节单位、夹爪方向及相机旋转。
- 15Hz更新动作预测，通过现有伺服接口执行当前时间对应的动作。chunk30表示预测时域约2秒，接入时明确重规划及时间集成逻辑。
- 当前任务以左臂操作，右臂保持已确认姿态。按现场最新安全和标定配置确定执行范围、速度和停止条件。
- 完成接入后安排10次同分布试验，记录抓取、对准插入、松爪和撤离各阶段结果、人工干预及失败原因，再决定需要补采的数据。

## 建议的执行顺序

实际推理离线评估 → 选择候选checkpoint并决定是否续训到20000步 → 实时推理接入 → 10次完整任务试验 → 根据失败阶段补采。

当前优先级最高的是第一步。正式训练已经产生可评估模型，下一轮工作应先把模型输出误差与任务动作对应起来。
