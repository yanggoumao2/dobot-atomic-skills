# 视觉引导抓取技术路线（讨论稿）

日期：2026-11-03。状态：设计讨论，尚未实现。下次从“待定事项”继续。

## 目标

相机看到要抓的物体，机械臂移过去抓取。物体位置可以变化，抓取要准。现有的示教点位运控保留为默认模式，视觉作为可切换的另一种模式。

## 现状（读代码确认）

- 6 个原子（`move_joint`、`move_linear`、`move_to_home`、`gripper.set_position`、`rotate_about_pivot`、`hold`）全部是开环运动，目标来自 profile 里的示教点位。倾倒路点由示教位姿几何推算。
- 上游引导图只支持 `embodied.pour`（beaker→tube），由 `choreography.py` 按固定模板展开成 20 个原子；调度是依赖驱动的 DAG，每臂同时一个原子，任一失败即停机并隔离。`decision_agent` 只在契约里声明，未实现。
- 代码里有三台 RealSense：`top`、`left_wrist`、`right_wrist`（`scripts/script_collect2train.py:54`）。手腕相机是否实际安装可用，待确认。
- 顶部相机到基座的棋盘标定向导在 `task_skills/calibration/`，只做过离线测试，未提交。

## 路线：由粗到精

1. **粗定位（顶部相机）**：棋盘标定（已选定，固定棋盘 + TCP 对角点 + PnP），左右臂各一次。把物体位置换算到基座坐标，精度只需让物体进入手腕相机视野（几毫米）。
2. **移到观察位**：物体上方留安全高度，开环运动。
3. **精定位（手腕相机）**：闭环对准示教参考。
   - 示教时在完美的抓取准备位记录物体特征（不是整张图）。
   - 运行时“看一眼动一下”，直到特征误差低于阈值（如 0.5 mm）。
   - 不用棋盘手眼标定：示教时让机械臂沿 x、y 各移动约 5 mm 并转一个小角度，自动估计该位置的局部图像雅可比。内参用 RealSense 出厂值。
   - 若闭环收敛慢或不稳，再补棋盘手眼标定（AX=XB）。
4. **相对抓取**：从对准位置按示教的相对动作直线下降、夹紧。放回时用本次对准后的位姿，不用示教点位。
5. **抓取确认**：夹爪位置反馈不能证明持物，用手腕相机确认物体在夹爪中。

## 识别

- 第一版：AprilTag 平贴在托座或试管架顶面，高度量准，物体在托座中位置固定。
- 第二版：无标记识别（自有数据训练检测、分割，识别杯口和管口边缘）。
- 透明玻璃使 RealSense 深度不可靠，用彩色图加已知高度。
- 只比较物体特征，不比较整张画面，因此对背景的要求是“别太乱”。低成本措施：哑光纯色桌垫、手腕环形补光、识别杯口边缘、液体加色。

## 集成方式

- 开关：`embodied.pour` 参数 `localization: taught | vision`，默认 `taught`，示教模式输出必须与现有参考 JSON 完全一致。网关另加 `--allow-vision` 闸门，并要求标定已通过真机验收。
- 视觉模式展开时在抓取前插入新原子：`perception.localize_global` → `arm.move_to_observe` → `servo.align_wrist`，再接原来的 `insert → close`。
- driver 的 `_pose()` 先查本次运行解析出的位姿覆盖表，再查 profile。
- 安全闸门：修正量上限（如平移 30 mm、偏航 10°，数值待定）；检测置信度阈值；定位后、运动前重做 IK/FK 往返检查和 j5 余量检查；失败即停机，不静默回退到示教点位。
- 机械兜底：夹爪指尖做 V 形槽或导向斜面，可吸收 1–3 mm 误差。

## 分阶段与验收

| 阶段 | 内容 | 验收 |
|---|---|---|
| 0 | 开关 + 新原子 + 模拟相机（离线） | 示教模式回归一致；视觉模式在预览页正确展开 |
| 1 | 顶部相机棋盘标定 + 真机验收 | 独立验收点误差（mm） |
| 2 | 顶部相机 + AprilTag 粗定位抓取 | 规定区域随机摆放 20 次的成功率 |
| 3 | 手腕闭环精对准 | 对准残余误差；同样 20 次的成功率 |
| 4 | 无标记识别 | 同样 20 次，并在更换背景、光照、加杂物条件下测试 |

标定前先固定相机安装和分辨率，棋盘放在物体所在桌面，第 7 步独立验收点至少 3 个并覆盖物体可能出现的区域。
