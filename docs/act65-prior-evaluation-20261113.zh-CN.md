# ACT首轮实际推理评估

评估对象为主机 `runs/act65_seed0_b8_10k_20261113_215406`。best为9000步，last为10000步。使用固定10条验证episode和训练时保存的55条训练归一化统计，调用 `policy(qpos,image)`。

## 评估范围

1. 全部2498帧各预测一个30帧动作块，汇总每个动作块第1步误差，生成连续曲线。
2. 既有50个固定窗口汇总30帧预测误差，去掉padding后共1210个有效目标动作。
3. 对照基线为每个窗口持续保持观测到的qpos。

图像和动作处理沿用训练契约。关节误差转换为度。夹爪范围为0到1，二值开合判定采用本次选定的0.5阈值。输出保留原始预测值，以观察超出范围和切换抖动。

## 结果

| 指标 | best / 9000步 | last / 10000步 | 保持qpos基线 |
|---|---:|---:|---:|
| 全帧第1步左臂关节MAE | 1.450° | 1.326° | 0.635° |
| 全帧第1步左臂关节P95 | 4.652° | 4.654° | 3.237° |
| 全帧第1步左夹爪MAE | 0.0618 | 0.0588 | 0.1211 |
| 全帧第1步夹爪开合一致率 | 97.92% | 97.76% | 97.48% |
| 固定窗口30步左臂关节MAE | 2.826° | 2.816° | 4.251° |
| 固定窗口30步左臂关节P95 | 9.687° | 10.320° | 22.582° |
| 固定窗口30步左夹爪MAE | 0.0843 | 0.0851 | 0.2004 |

last的30步关节MAE较基线降低约33.7%，夹爪MAE降低约57.5%。单步关节MAE仍高于保持姿态基线。基线的单步误差较小与相邻时刻动作变化较小有关，结合30步指标和连续曲线判断模型的动作预测能力。

last左臂J1至J6单步MAE分别为0.699°、1.945°、2.365°、1.580°、0.472°、0.894°，误差主要集中在J2、J3和J4。验证episode57误差最大，单步平均2.874°，P95为9.602°。其多个关节在示教保持某些姿态时出现连续偏移。

使用0.5夹爪阈值，每条示教包含一次闭合和一次打开。last首次闭合时刻的平均绝对偏差约0.133秒，最终打开时刻约0.227秒，最大偏差0.4秒。episode2和63各出现两次额外阈值穿越，表示切换附近反复。这里将首次预测穿越作为闭合、最终预测穿越作为打开，作为时序诊断，后续执行策略需另外明确夹爪控制逻辑。

## 结论与建议

模型已经学到主要轨迹和夹爪状态变化。last的单步平均误差优于best，但best的30步尾部误差和夹爪切换稳定性略好。暂以last作为续训起点，两个模型都保留用于后续对比。

下一轮建议累计训练到20000步，沿用当前主要参数，并把本次实际推理指标加入每次固定验证。重点观察单步左臂关节MAE、J2/J3误差、30步P95以及夹爪切换反复次数。若这些指标没有改善，结合episode57等高误差样本检查动作分布和阶段覆盖，再安排针对性数据补采。细窄口插入的执行精度还需要真机标定和闭环试验测量。

本次完成的是记录观测下的离线预测评估。连续曲线中每一帧都使用真实观测状态和图像，实际闭环执行中的状态偏移及任务成功率需要后续试验获得。

## epoch换算

训练入口采用optimizer steps和有放回随机episode/起点采样，当前为10000步、batch8，共80000个窗口样本。

- 按每条episode抽一个窗口的一轮抽样量计算，80000/55约为1454.55个等效episode采样轮次。
- 若以13825个训练帧起点的一次扫描量计算，80000/13825约为5.79遍采样量。当前实际按episode均匀采样，较短episode的帧起点抽样频率会更高。
- 如果按常见ACT DataLoader每轮55条episode、最后一个batch为7条计算，每轮有ceil(55/8)=7个batch，10000步对应约1428.57个这样的批次轮数。与1454.55的差异来自本次所有batch都含8个样本。
- 本次入口没有维护epoch计数。make_policy中用于上游parser的num_epochs=1是模型构建占位参数，训练循环由steps控制。
